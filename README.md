# FSI Toolbox

The FSI Toolbox is a shared catalog for discovering, reusing, and contributing
accelerators, reference implementations, tools, assets, and best practices for
financial services industry (FSI) customer scenarios.

Bringing these efforts together helps the FSI community:

- make valuable work easier to discover;
- reduce duplicated effort;
- accelerate customer engagements;
- promote reusable, well-maintained patterns; and
- increase the impact of contributions across the team.

## Browse the toolbox

Assets are listed in [`catalog/catalog.json`](catalog/catalog.json). Each entry
includes its purpose, scenario, maturity, maintainers, and source repository.
The catalog is intentionally lightweight: assets remain in their existing
repositories while this repository provides a central discovery and
contribution experience.

Microsoft Fabric assets can also be browsed by workload in the
[`Fabric`](Fabric/README.md) folder.

| Category | Examples |
| --- | --- |
| Accelerators | Deployable solutions and engagement starters |
| Reference architectures | Proven architecture patterns and guidance |
| Samples | Focused code examples and demonstrations |
| Tools | Utilities, automation, and developer tooling |
| Best practices | Playbooks, checklists, and implementation guidance |

## Contribute

Every contribution matters. You can:

1. [Propose an existing asset](../../issues/new?template=asset-proposal.yml).
2. Add an asset directly by following [CONTRIBUTING.md](CONTRIBUTING.md).
3. Suggest an improvement or report a catalog issue.
4. Help review, test, document, or maintain an existing asset.

New to contributing? Share the step-by-step
[Contributor Guide](docs/FSI-Toolbox-Contributor-Guide.docx) with colleagues.

Catalog entries are validated automatically on every pull request.

## Principles

- **Discoverable:** entries clearly state the scenario, audience, and value.
- **Reusable:** assets include enough documentation to adopt and adapt them.
- **Responsible:** assets follow applicable security, privacy, compliance, and
  responsible AI practices.
- **Maintained:** every entry identifies accountable maintainers and maturity.
- **Inclusive:** contributions and constructive feedback are welcome from
  across the FSI community.
