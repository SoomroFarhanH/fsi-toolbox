# Support

The FSI Toolbox is a community-driven catalog. Inclusion does not create a
Microsoft product support commitment.

- For catalog metadata, contribution, or discovery problems, open an issue in
  this repository.
- For an asset-specific bug or question, use the issue tracker in that asset's
  source repository.
- For Microsoft product support, use the official support channel associated
  with that product or service.

Do not include credentials, customer data, personal data, or other confidential
information in issues or discussions.
