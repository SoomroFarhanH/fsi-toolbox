# Security

Please do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities in Microsoft-owned assets through the
[Microsoft Security Response Center](https://aka.ms/security.md). For
third-party assets listed in the catalog, follow the security reporting process
in the asset's source repository.

Catalog inclusion does not imply that Microsoft has independently audited or
endorsed an asset. Users remain responsible for evaluating security, privacy,
compliance, and operational suitability for their environment.
