# Microsoft Fabric

This folder organizes FSI Toolbox assets by the current top-level Microsoft
Fabric workloads documented in the
[Microsoft Fabric overview](https://learn.microsoft.com/fabric/fundamentals/microsoft-fabric-overview).

| Workload | Folder |
| --- | --- |
| Power BI | [power-bi](power-bi/) |
| Databases | [databases](databases/) |
| Data Factory | [data-factory](data-factory/) |
| Industry Solutions | [industry-solutions](industry-solutions/) |
| Real-Time Intelligence | [real-time-intelligence](real-time-intelligence/) |
| Data Engineering | [data-engineering](data-engineering/) |
| Data Science | [data-science](data-science/) |
| Data Warehouse | [data-warehouse](data-warehouse/) |
| Fabric IQ | [fabric-iq](fabric-iq/) |

Place an asset in the workload that best represents its primary purpose. For
cross-workload solutions, choose one primary folder and link to it from the
other relevant workload folders rather than duplicating the asset.
